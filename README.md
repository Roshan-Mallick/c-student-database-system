# Advanced Student Database System in C

An advanced C programming project demonstrating:

- Dynamic Memory Allocation
- Binary File Handling
- Persistent Data Storage
- Structures
- Heap Memory Management
- Modular C Design
- System-Level Programming Concepts

---

# Features

- Add new student records
- View all students
- Search student by ID
- Delete student records
- Persistent binary database storage
- Automatic database folder creation
- Dynamic memory management using:
  - malloc()
  - calloc()
  - realloc()
  - free()

---

# Technologies Used

- C Programming
- GCC Compiler
- Binary Files
- Dynamic Memory Allocation
- Structures
- File Handling
- System Calls
